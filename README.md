# MetaXR_Quest3_Starter

A Unity 6.3 LTS starter template for Meta Quest 3 development.

## Requirements
- Unity 6.3 LTS
- Meta Quest 3
- Meta XR SDK 207

## Includes:

- Meta XR SDK 207
- OpenXR
- XR Hands
- Hand Tracking
- Meta XR Camera Rig
- Meta Quest Platform Configuration
- Starter Scene
- Test Plane and Cube

## Verified Features:

- Head Tracking
- Hand Tracking
- Build And Run Deployment

Tested on Meta Quest 3.

This template is intended to help developers skip the initial project setup process and begin building immediately.

## Getting Started

1. Clone the repository.
2. Open the project using Unity 6.3 LTS.
3. Open StarterScene.
4. Connect a Meta Quest 3 headset.
5. Select Meta Quest as the active platform.
6. Use Build And Run to deploy to the headset.
